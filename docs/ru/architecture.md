# Устройство программы

Программа разделяет интерфейс Qt и проверяемые модули Python для состояния проекта, сканирования, обработки файлов, предложений названий, хранения данных и экспорта порядка публикации. Долгое сканирование и операции с медиа выполняются вне потока интерфейса.

Принятое поведение описано в `docs/PLAN.md`. Выполняйте по одному заданию из локального списка `.work-memory/TASKS.md`. Проекты и журналы остаются в локальных данных приложения; автоматические проверки используют искусственные примеры.

Программа не отправляет файлы в Telegram. Отдельный загрузчик Telegram Media Sender принимает локальный версионированный файл `publication-plan.json`.
