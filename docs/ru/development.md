# Разработка

## Требования

- macOS 13 или новее на Apple Silicon
- Python 3.12
- Xcode Command Line Tools для упаковки приложения

## Настройка и проверки

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e .
PYTHONPATH=src QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
```

Модульные проверки должны работать предсказуемо, без сети, учебных папок, реального аккаунта Telegram и модельного сервиса. Используйте временные папки и небольшие искусственные данные. Проверяйте состав архивов и сохранность источников.

В локальной папке `.work-memory` хранятся статусы задач, точка продолжения и подтверждения проверок. Git игнорирует эту папку. Не переносите машинные данные в публичную документацию.

## Выпуск

Собирайте приложение из проверенного чистого коммита. Для каждого выпуска создавайте новую папку с номером версии. Не заменяйте предыдущий выпуск. Проверяйте именно архив приложения в отдельном каталоге данных. Перед публикацией пройдите выпускной список и проверьте репозиторий, архив, снимки экрана, лицензии и контрольную сумму.
