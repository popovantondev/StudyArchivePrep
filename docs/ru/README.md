# Study Archive Prep

**[Русский](README.md) · [Deutsch](../de/README.md) · [English](../../README.md)**

macOS 13 или новее · Apple Silicon · Версия 0.1.0

Study Archive Prep раскладывает учебные материалы по датам, помогает проверить записи и субтитры и готовит порядок публикации для Telegram Media Sender.

## Состояние проекта

Это ранняя версия в разработке. На первом экране можно выбрать исходные папки и отдельную папку результата. Сканирование, обработка, экспорт плана публикации и предложения названий пока разрабатываются. Эта версия не отправляет сообщения в Telegram.

## Запуск из исходников

Для сборки нужен Python 3.12 на macOS.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e .
study-archive-prep
```

Для отдельного просмотра интерфейса передайте `--data-dir /tmp/study-archive-prep-preview`. Этот параметр перенаправляет локальные настройки и данные приложения.

## Сохранность и приватность

Пользователь выбирает исходные папки. Эта версия ещё не сканирует и не отправляет в Telegram файлы. Не добавляйте в Git учебные материалы, текст субтитров, личные пути, локальные проекты, веса моделей, данные аккаунтов или журналы программы.

Программа использует SQLite и будет предлагать названия с помощью локальной языковой модели. Модель загружается только по явной просьбе и не хранится в репозитории. См. [права и уведомления о сторонних компонентах](../../THIRD_PARTY_NOTICES.md).
