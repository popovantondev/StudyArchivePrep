# Решения проекта

## D001 — отдельная программа для подготовки

Подготовка файлов живёт в новом репозитории StudyArchivePrep; TelegramMediaSender остаётся загрузчиком. Связь между ними — версионированный относительный `publication-plan.json`.

## D002 — авторитетная память в файлах проекта

Требования и решения хранятся в Git (`docs/PLAN.md`, `docs/DECISIONS.md`). Состояние поручений, продолжения и подробных проверок хранится локально в `.work-memory/`, исключённой из Git. Каждый переход статуса содержит точный результат проверки и commit/path evidence. Текст чата или сообщение «готово» сам по себе не закрывает задачу.

## D003 — выполнение по одному поручению

GPT-6 Luna, medium реализует одно задание за раз. После сдачи основной разработчик проверяет diff, указанную команду и критерий приёмки, затем обновляет локальную память. Два подряд провала одного задания означают остановку и запись блокера для разбора; задачу не перескакивать и попытки бесконечно не повторять.

## D004 — исходные данные защищены

Операции подготовки копируют в выбранную папку результата. Удаление исходной записи выключено по умолчанию и разрешается только после проверенного извлечения, показа списка, подтверждения и проверки неизменности оригинала. Никакие другие источники не удаляются программой.

## D005 — локальное создание названий

Первичная модель — Qwen3-4B GGUF Q4_K_M на llama.cpp, выбирается неизменяемый commit модели и проверенная сборка движка с уведомлениями. Весы скачиваются отдельно, по кнопке. SRT не отправляются в облако. Пользователь подтверждает каждое название.

## D006 — ручной план публикации

Пользователь может свободно переставлять недели, дни, файлы и текстовые блоки до экспорта. Загрузчик принимает JSON только по известной схеме, сверяет файл до отправки, отдельно показывает итоговый порядок и не отправляет манифест как материал.

## D007 — публичный репозиторий

Новый GitHub-репозиторий создаётся после санитарной проверки. Пользовательские пути, материалы, скриншоты, проекты, логи, модель и сессии не публикуются. Собственный код сохраняет авторство; лицензии сторонних компонентов соблюдаются.
