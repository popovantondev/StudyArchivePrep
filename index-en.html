Before you startEarly development: source only, no ready-to-install package. Python 3.12; set up the local model and engine separately for title suggestions.

What's inside

Installation, features, data flow and checks.

Installation

The steps from “Run from source” in the guide (Python 3.12, macOS).

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e .
study-archive-prep
# Isolated UI preview: study-archive-prep --data-dir /tmp/study-archive-prep-preview

Your data

Files are not uploaded. The model for title suggestions is downloaded only after an explicit click.
