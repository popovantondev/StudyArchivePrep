Study Archive Prep

Организует учебные материалы по датам, извлекает аудио и готовит порядок публикации для Telegram Media Sender.

Только исходники · 0.1.0 macOS 13+ · Apple Silicon
Исходный код Python · PySide6 Руководство ↗

Перед запускомРанняя разработка: доступны исходники, готового установочного пакета нет. Python 3.12; локальная модель и движок для подсказок заголовков устанавливаются отдельно.

Что внутри

Установка, функции, передача данных и проверка.

Установка

Шаги из раздела «Запуск из исходников» руководства (Python 3.12, macOS).

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e .
study-archive-prep
# Отдельный просмотр интерфейса: study-archive-prep --data-dir /tmp/study-archive-prep-preview

Ваши данные

Файлы не загружаются. Модель для подсказок заголовков скачивается только после явного нажатия кнопки.

Работает локально

Первые шаги
