Study Archive Prep

Организует учебные материалы по датам, извлекает аудио и готовит порядок публикации для Telegram Media Sender.

Исходный кодРуководство ↗

Перед запускомРанняя разработка: доступны исходники, готового установочного пакета нет. Python 3.12; локальная модель и движок для подсказок заголовков устанавливаются отдельно.

Готового установочного пакета нет. Инструкции описывают настройку из исходников.

Как это работает

  1. Настроить исходники
  2. Подготовить материалы
  3. Упорядочить архив

Первые шаги

Откройте руководство запуска из исходников. Программа сама не отправляет материалы в Telegram.
