Study Archive Prep

Ordnet Lernmaterial nach Datum, extrahiert Audio und bereitet die Reihenfolge für Telegram Media Sender vor.

Nur Quellcode · 0.1.0 macOS 13+ · Apple Silicon
Quellcode Python · PySide6 Anleitung ↗

Vor dem StartFrühe Entwicklung: nur Quellcode, kein fertiges Installationspaket. Python 3.12; lokales Modell und Engine für Titelvorschläge separat einrichten.

Was drin steckt

Installation, Funktionen, Datenverbindung und Prüfung.

Installation

Die Schritte aus „Aus den Quellen starten“ in der Anleitung (Python 3.12, macOS).

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e .
study-archive-prep
# Getrennte UI-Vorschau: study-archive-prep --data-dir /tmp/study-archive-prep-preview

Ihre Daten

Dateien werden nicht hochgeladen. Das Modell für die Titelvorschläge wird nur nach einem ausdrücklichen Klick heruntergeladen.
